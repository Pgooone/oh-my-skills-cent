# Web 版无认证，仅监听 localhost

Web 版为单用户单机语义，不实现任何认证层；HTTP 服务只绑定 `127.0.0.1`，公网访问由用户自行经 SSH 隧道或带认证的反向代理。用户明确接受此取舍（QA 决策文档 Q6，偏离了「可选 token」推荐）。

## Consequences

- **护栏**：绑定地址非 localhost 时拒绝启动并打印原因——不开门比开门不锁安全。
- **防 CSRF/DNS rebinding**：仅监听 localhost ≠ 只有本机进程能访问，浏览器内任意网页都能向 127.0.0.1 发请求。HTTP 层必须校验 `Host` 头为 localhost 且拒绝跨源写请求（QA 决策文档 D8）。
- 部署文档必须显式包含 SSH 隧道（`ssh -L`）访问指南。
- 任何未来的多用户/公网需求都必须先重开本 ADR，再谈实现。
