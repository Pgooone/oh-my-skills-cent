# 打包技能采用结构化拷贝

打包技能（ADR-0004 的输出形态之一）是自包含目录：`SKILL.md` 只写工作流级编排说明（分组 → 步骤 → 每步该做什么），`skills/` 子目录放各被引用 Skill 的**完整拷贝**。不做文本合并。

## Considered Options

- **文本内联**（各 Skill 的 SKILL.md 全文合并进一个文件）：内容膨胀，源 Skill 更新后打包版即过期，被拒绝。
- **纯引用**（只写引用列表，依赖各 Skill 独立安装）：不自包含，失去「便携分发」这一打包形态的独特价值，被拒绝。

## Consequences

- 源 Skill 更新后，打包技能整目录重新生成即可，无增量合并逻辑。
- Agent 消费方式：先读入口 SKILL.md，再按指引读取 `skills/` 子目录中的对应 Skill。
