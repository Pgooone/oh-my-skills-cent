# Oh My Skills v0.1.2

## 中文

### 概述

v0.1.2 聚焦同步流程与 Skills 列表体验：支持 Skill 替换同步、更清晰的引用位置展示，以及同步预览/结果界面的布局优化。

### 下载

| 平台 | 文件 |
|------|------|
| macOS（Apple Silicon） | `Oh My Skills_0.1.2_aarch64.dmg` |

安装：打开 DMG，将应用拖入「应用程序」文件夹。  
若首次打开被系统拦截，请到「系统设置 → 隐私与安全性」允许，或右键应用选择「打开」。

> 说明：当前为本地构建版本，尚未做 Apple 公证与自动更新。

### 新功能

**同步支持替换（replacements）**  
同步预览与执行可处理 Skill 替换场景，计划摘要会区分新增与替换类操作，避免覆盖意图不清晰。

**选择与排队同步更稳**  
Skills 跨工作区使用更稳定的选择标识（selectionKey），并跟踪已排队同步的 Skill，减少列表与同步页之间的状态错乱。

**中心库引用位置**  
中心库视图展示 Skill 的引用位置（不再只是「引用次数」），便于判断该 Skill 已分发到哪里。

### 改进

- **同步预览布局**：Sync 表单、确认区与预览信息分区更清晰，细节按需展开
- **同步结果展示**：执行结果区域对齐、溢出与可读性更好
- **Skill 详情路径**：详情中的路径信息按工作区上下文组织，结构更易扫读
- **Skills 表格布局**：列表列宽与对齐统一，多选与滚动体验更一致
- **项目根目录处理**：扫描与同步相关逻辑对项目分发场景更明确
- **CI**：Release 工作流支持手动触发构建并上传安装包产物；TRAE 应用名测试跨平台

### 修复

- TRAE 应用名相关测试在 Windows 上按 `.exe` 期望，避免误失败

### 已知限制

- 尚未提供代码签名、公证与自动更新
- Windows 软链接同步仍依赖 Developer Mode 或管理员权限；不可用时会回退为复制
- 仍为 MVP 阶段，功能以「发现 → 预览 → 确认 → 同步」为主流程

### 从 v0.1.1 升级

直接安装 v0.1.2 覆盖即可，中心库路径与已有 Skills 数据会保留。

### 构建产物

```
src-tauri/target/release/bundle/dmg/Oh My Skills_0.1.2_aarch64.dmg
src-tauri/target/release/bundle/macos/Oh My Skills.app
```

## English

### Overview

v0.1.2 focuses on the sync flow and Skills list experience: replacement-aware sync, clearer reference-location display, and layout polish for sync preview and results.

### Downloads

| Platform | File |
|----------|------|
| macOS (Apple Silicon) | `Oh My Skills_0.1.2_aarch64.dmg` |

Install by opening the DMG and dragging the app into Applications.  
If macOS blocks the app on first launch, allow it under **System Settings → Privacy & Security**, or right-click the app and choose **Open**.

> Note: This is a local release build without Apple notarization or auto-update.

### What's New

**Replacement-aware sync**  
Sync preview and execution can handle skill replacements. Plan summaries distinguish create vs replace operations so overwrite intent is clearer.

**More stable selection and queued sync**  
Skills use a stable selection key across workspaces, and the app tracks skills queued for sync to reduce state mismatch between the list and sync page.

**Library reference locations**  
The central library view shows where a skill is referenced (not just a count), making distribution status easier to scan.

### Improvements

- Clearer sync form, confirmation, and preview layout with progressive disclosure
- Better apply-result alignment, overflow handling, and readability
- Skill detail path sections organized by workspace context
- Consistent skill table column layout and multi-select scrolling
- Clearer project-root handling for project distribution scenarios
- Release workflow supports manual dispatch with installer artifacts; TRAE app-name tests are cross-platform

### Fixes

- TRAE app-name tests expect `.exe` on Windows to avoid false failures

### Known Limitations

- No code signing, notarization, or auto-update yet
- Windows symlink sync still requires Developer Mode or administrator privileges; copy fallback remains available
- Still an MVP focused on discover → preview → confirm → sync

### Upgrading from v0.1.1

Install v0.1.2 over the existing app. Your library path and existing skill data are preserved.

### Build Artifacts

