# Oh My Skills v0.1.3

## 中文

### 概述

v0.1.3 聚焦设置、Skills 管理与同步详情：支持自定义根路径、全局路径移除，以及同步计划详情与目标选择的体验打磨。

### 下载

| 平台 | 文件 |
|------|------|
| macOS（Apple Silicon） | `Oh My Skills_0.1.3_aarch64.dmg` |

安装：打开 DMG，将应用拖入「应用程序」文件夹。  
若首次打开被系统拦截，请到「系统设置 → 隐私与安全性」允许，或右键应用选择「打开」。

> 说明：当前为本地构建版本，尚未做 Apple 公证与自动更新。

### 新功能

**设置：自定义根路径**  
设置面板支持管理自定义根路径，布局与信息层级更清晰，便于按本机目录结构组织扫描范围。

**全局路径移除**  
Skills 列表支持移除全局路径引用，减少无效或过时路径干扰，列表更干净。

**同步计划详情面板**  
同步预览可展开查看计划详情，目标选择与计划摘要更易对照，确认写入前心里更有底。

### 改进

- **同步目标选择**：Sync 页目标选择状态与布局更稳定，预览信息分区更清楚
- **问题提示与本地化**：Skill 问题处理相关文案与展示更清晰
- **引用位置展示**：Skill 引用单元格排版与字号优化，扫读更快
- **项目工具栏与筛选**：项目 chip、工具栏与摘要区布局更易用
- **列表与选择栏**：Skills / Sync 页按钮样式与已选数量展示更一致
- **响应式布局**：Skills 页在常见窗口尺寸下的可用性更好

### 已知限制

- 尚未提供代码签名、公证与自动更新
- Windows 软链接同步仍依赖 Developer Mode 或管理员权限；不可用时会回退为复制
- 仍为 MVP 阶段，功能以「发现 → 预览 → 确认 → 同步」为主流程

### 从 v0.1.2 升级

直接安装 v0.1.3 覆盖即可，中心库路径与已有 Skills 数据会保留。

### 构建产物

```
src-tauri/target/release/bundle/dmg/Oh My Skills_0.1.3_aarch64.dmg
src-tauri/target/release/bundle/macos/Oh My Skills.app
```

## English

### Overview

v0.1.3 focuses on settings, skill path management, and sync plan details: custom root paths, global path removal, and clearer sync plan / target-selection UX.

### Downloads

| Platform | File |
|----------|------|
| macOS (Apple Silicon) | `Oh My Skills_0.1.3_aarch64.dmg` |

Install by opening the DMG and dragging the app into Applications.  
If macOS blocks the app on first launch, allow it under **System Settings → Privacy & Security**, or right-click the app and choose **Open**.

> Note: This is a local release build without Apple notarization or auto-update.

### What's New

**Custom root paths in Settings**  
The settings sheet supports managing custom root paths, with clearer layout and information hierarchy for organizing scan scope.

**Global path removal**  
Skills list can remove global path references so stale or unwanted paths stop cluttering the view.

**Sync plan detail panel**  
Sync preview can expand into a plan detail panel so target selection and plan summary are easier to compare before write.

### Improvements

- More stable sync target selection state and layout
- Clearer skill issue messaging and localization
- Cleaner skill reference cell typography and layout
- More usable project toolbar, chips, and summary areas
- Consistent button styles and selection-count display on Skills / Sync
- Better Skills page usability at common window sizes

### Known Limitations

- No code signing, notarization, or auto-update yet
- Windows symlink sync still requires Developer Mode or administrator privileges; copy fallback remains available
- Still an MVP focused on discover → preview → confirm → sync

### Upgrading from v0.1.2

Install v0.1.3 over the existing app. Your library path and existing skill data are preserved.
